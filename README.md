# Books to Scrape Scraper

## Target classification

- **Site:** https://books.toscrape.com
- **Why this site:** toscrape.com describes Books to Scrape as a fictional bookstore built for people to practise web scraping on. That statement is the permission for this project.
- **Scope:** the first 3 catalogue pages only (60 books).
- **Data collected:** title, price, availability, rating, and the book's page URL.
- **robots.txt result:** I requested https://books.toscrape.com/robots.txt once. It returned 404, so no robots file was found. A missing file is not permission by itself; the site's own statement is.
- **Why this is appropriate:** the site exists for scraping practice, and I am only collecting a small amount of fake bookstore data at a slow, polite pace.

I will not reuse this code on another site without checking its rules and terms first.
